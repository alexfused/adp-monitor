ADP Monitor

Monitoring and remote control for the Macs that run venue shows. By Parkin Systems.

What it does

ADP Monitor runs on the Macs in a venue (lighting, sound, video and music playback). The iPhone and iPad app connects to them so a technician can see their health, fix common problems, change fan behaviour, and control a Mac's screen from anywhere on the venue's own network or over Tailscale.

Getting started

  1. Install ADP Monitor on each venue Mac and turn on Share this Mac with the fleet.
  2. On your main Mac, open Fleet and press Pair iPhone….
  3. In the iPhone or iPad app, choose Scan pairing code and point the camera at the code.
  4. Away from the venue, run Tailscale on the phone and the Macs.

No Mac to hand? Choose Try the demo in the app to explore a pretend venue Mac.

Help

  • A Mac shows offline: check it is awake, ADP Monitor is open on it, and both devices are on the same network or on Tailscale.
  • Remote screen is black: on that Mac, allow Screen Recording and Accessibility for ADP Monitor in System Settings, Privacy & Security.
  • Pairing code rejected: make a fresh code on the Mac and scan again.
